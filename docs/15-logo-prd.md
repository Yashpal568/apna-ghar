# Apna Ghar Logo PRD — Brand Lock

## Status
Brand asset constraint for all design and implementation work. The previously selected Apna Ghar logo concept is the source of truth: a premium blue-and-green house/roof mark paired with the “Apna Ghar” wordmark.

## Non-negotiable rule
Do not redesign, replace, reinterpret, or generate a new logo. Do not substitute a generic “AG” monogram, text-only mark, new house icon, alternate roof geometry, or a different symbol. Use the exact approved logo asset when it is supplied in the project files.

## Allowed variants
- Primary full-color logo for light surfaces.
- Approved light/dark-surface variant for sufficient contrast.
- App icon/cropped mark only if it uses the exact same approved house/roof symbol without changing its geometry.
- Monochrome version only if needed for a constrained context and approved; it must not replace the primary brand asset.

## Theme requirements
The logo must remain consistent across Light Classic, Midnight, Graphite, Forest, and AMOLED Black. Only approved color/contrast adaptations are allowed. Never invent a different symbol to fit a theme.

## Design-tool instructions
Google Stitch, Figma, code-generation tools, and developers must use the supplied approved logo asset. If the source asset is not available in the design workspace, use a clearly marked placeholder reading “INSERT APPROVED APNA GHAR LOGO ASSET”; do not fabricate a substitute.

## Asset handoff
Keep source logo files in a dedicated brand/assets location with descriptive filenames. Preserve original dimensions and transparency where available. Do not crop, stretch, distort, or embed the entire branding sheet as the production logo. Record the final asset filename and format once the approved source file is provided.

## Acceptance criteria
- The same approved house/roof symbol is visible across all five themes.
- The “Apna Ghar” wordmark remains consistent.
- No generic AG logo or AI-invented replacement appears in production screens.
- Light and dark variants preserve the same recognizable mark.
- Missing source asset is flagged rather than guessed.
