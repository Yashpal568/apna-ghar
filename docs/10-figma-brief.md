# Figma Design Brief

Design Apna Ghar as a premium Indian property marketplace. Primary blue #2563EB, green #10B981, navy #0F172A, light background #F3F4F6, white #FFFFFF. Use refined typography, high-quality property photos, clear INR pricing, generous spacing and accessible contrast.

Create separate assets for: main horizontal wordmark, light-surface small logo, dark-surface alternate logo, and launcher icon. Do not use the entire branding sheet as a production logo. Follow the system light/dark theme.

Screens: onboarding, Clerk sign-in/up, home, categories, search/filter, list/map results, property details with image/video gallery, post listing, my listings, favorites, profile, report listing, admin overview, listings/users/categories/reports, feature catalog, subscription plan matrix, app config and audit log. No pending state. Listings publish immediately. All users are Free at launch, but plans/entitlements are configurable. Provide responsive SEO web and dedicated admin designs.
