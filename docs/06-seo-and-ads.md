# SEO, AdMob and AdSense

## Web SEO
React Native screens do not replace crawlable web pages. Use Next.js SSR/SSG for public property pages. Include unique titles/descriptions, canonical URLs, Open Graph, server-rendered listing details, sitemap, robots.txt, breadcrumbs, optimized images and accurate structured data. Protect/noindex account and admin pages. Avoid indexing infinite filter combinations or thin location pages.

## Ads
- AdMob for native mobile ads; start with test ad units and add after core UX is stable.
- AdSense only on eligible web pages after site/account approval and policy review.
- Keep ads clearly labelled and away from property/contact controls.
- No ads on admin/login/private account flows.
- Remote-configurable placements and a kill switch are required.
- Review privacy/consent and store policies before release.
