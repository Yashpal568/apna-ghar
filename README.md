# Apna Ghar

Premium Indian real-estate buy/sell marketplace. This repository currently contains the product blueprint and implementation plan. The mobile framework decision (Expo vs React Native Community CLI) is intentionally open until reviewed.

## Confirmed stack decisions
- Clerk for authentication
- MongoDB for application data
- React Native for mobile (Expo vs CLI TBD)
- Next.js for SEO-friendly web
- Dedicated protected admin panel
- AdMob for mobile ads; AdSense for eligible web pages
- Dynamic plans/features/entitlements in backend, all users Free and payments disabled at launch
- Blue + green brand, with system light/dark logo variants

Read `docs/` before implementation. See `prompts/` for coding-agent prompts. Do not commit secrets.
