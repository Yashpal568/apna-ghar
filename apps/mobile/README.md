# React Native Community CLI mobile app

Framework decision: React Native Community CLI (not Expo).

## Scaffold status
The full native Android/iOS project has not been generated yet. Generate it with the React Native Community CLI in a compatible local environment, then merge it into this folder without overwriting the root workspace. Android requires Node.js, Android Studio, JDK and Android SDK; local iOS builds require macOS and Xcode.

This README is not a runnable mobile app. Native scaffolding remains an M1 acceptance item.
